📚 Setup Instructions & Troubleshooting
Quick Setup Guide:
  1. Create a new Google Sheet (or use existing)
  2. Copy the Sheet ID from the URL
  3. Set up Google Cloud API (see detailed guide below)
  4. Paste Sheet ID and API Key above
  5. Click "Test Connection" to verify
  6. Enable tracking and save settings
Common Issues:
  • Connection Failed: Make sure sheet is shared "Anyone with link can view"
  • API Error: Check that Sheets API is enabled in Google Cloud
  • Permission Denied: Verify API key restrictions match your domain
  • Data Not Appearing: Check sheet tab name matches setting above
Need Help?

See the full setup documentation in the Google Sheet template.
